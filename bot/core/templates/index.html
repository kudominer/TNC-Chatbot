Vận Hành Guild Tự Động

6 hệ thống tích hợp — từ quản lý điểm số, tổ chức party, kiểm tra thành viên đến voice chat.

Siphoned Points

Parse file log `.txt` hoạt động bang hội, cộng dồn điểm siphoned theo người chơi, bảng xếp hạng phân trang.

Log Parser Leaderboard Phân Trang

Massing PVP/PVE

Khởi tạo party theo role & weapon, UI nút bấm join/kick/move/fill, lưu template, tự khôi phục sau restart.

Interactive UI Templates Auto Restore

GuildCheck

Đăng ký IGN, kiểm tra qua Albion API xem còn trong guild không, tự xóa role Discord nếu đã rời.

Albion API Auto Sync Role Manager

Alo Voice (TTS)

Đọc chat thành giọng nói qua gTTS vào voice channel, auto reconnect khi mất kết nối.

gTTS Voice Channel Auto Rejoin

Core & Bank

Auto react lên ảnh core nộp, quy đổi ra silver qua UnbelievaBoat, audit log đầy đủ.

Auto React UnbelievaBoat Audit Log

Sao Lưu Dữ Liệu

Cơ chế safe-write .tmp/.bak chống hỏng JSON, tự động git push dữ liệu lên GitHub định kỳ.

Safe-Write GitHub Sync JSON DB
